# Architecture decision records

Significant decisions of v2, in the format proposed by Michael Nygard ("Documenting
Architecture Decisions", 2011): context, decision, consequences. ADRs were written up at the
2.0.0 release; each records a decision taken while v2 was built, so its date is the release
date, not the date of the decision. A record is never edited to reverse a decision; a new
record supersedes it.

| [0006](0006-pre-specified-headline-and-nested-selection.md) | Pre-specified headline and nested feature selection | Accepted |

To add a record, copy the structure of an existing one, number it sequentially, and link it
here.
