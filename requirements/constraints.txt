# Reference versions of every package `pip install -e ".[dev,notebook]"` installs.

# the rendered figures, so CI installs with this file and the committed-artifact staleness
# tests then check that the results reproduce:
#
#     pip install -e ".[dev]" -c requirements/constraints.txt
#
# A constraints file only fixes versions; it installs nothing by itself, so one file serves
# every extra (core, [api], [report], [dev], [notebook]). It also pins the tool versions CI

#
# Scope: the dependency closure of battery-soh[dev,notebook] on Linux and macOS, Python 3.11
# and 3.12. Every pin has binary wheels for Linux x86_64, macOS arm64 and Windows x86_64 on
# both Python versions. Windows-only packages (pywinpty; colorama only for the lock, see
# below) and setuptools (packaging tooling, needed by jupyterlab) are deliberately not
# pinned. Refresh procedure: requirements/README.md.
